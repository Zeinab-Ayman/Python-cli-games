# 🎮 Python CLI Mini-Games Collection

A fun collection of classic games that run in the Command Line Interface (CLI / Terminal), built using Python.

---

## 🕹️ Included Games

1. **Hangman:** Guess the correct letters of the word before running out of attempts!
2. **Tic-Tac-Toe:** A classic 2-player grid game with win & draw validation.
3. **Number Guessing:** Try to guess the secret random number with helpful hints.

---

## ✨ Features

- **Interactive Main Menu:** Easy navigation to switch between games seamlessly.
- **Robust Error Handling:** Protects against invalid inputs (letters instead of numbers, etc.) to keep the game running smoothly.
- **Modular Code Design:** Clean structure separated into independent modules using Python best practices.

---

## 🚀 How to Run

1. Make sure you have **Python 3** installed on your machine.
2. Clone the repository, enter the folder, and run the game using these commands:

```bash
git clone https://github.com/Zeinab-Ayman/Python-cli-games.git
cd Python-cli-games
python main.py
